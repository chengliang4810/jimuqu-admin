## 字典管理

字典由类型和数据两部分组成。类型定义稳定键名，数据定义显示标签、存储值、排序、样式与状态。前端表单和列表可按字典类型获取选项，后端翻译模块可把存储值转换成标签。

字典变更后应刷新缓存。删除字典类型前，应检查业务字段和前端页面是否仍引用该类型键。

## 参数管理

系统参数适合保存可在线调整的非敏感业务开关，例如是否允许注册。可通过参数键查询或更新，并支持导出与缓存刷新。

以下内容不应放入参数管理：

- 数据库、Redis、SMTP 和对象存储密码
- RSA 私钥或第三方应用密钥
- 必须在应用启动前生效的框架配置

这些内容应通过环境变量或外部密钥管理系统提供。
