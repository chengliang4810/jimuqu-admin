## 用户管理

用户模块支持分页、按部门查询、详情、创建、修改、删除、密码重置、状态切换、角色授权、账号解锁以及 Excel 导入导出。

新增或修改用户时，业务对象负责字段校验，Service 负责用户名、手机号、邮箱等唯一性与角色岗位关系维护。删除用户前应检查是否允许删除内置或当前登录账号。

## 部门管理

部门使用树形结构组织公司、部门和小组，也是数据权限计算的基础。`/system/dept/list/exclude/{deptId}` 用于编辑时排除当前部门及不允许的节点，防止形成循环父子关系。

## 岗位管理

岗位用于描述用户在组织中的职务，可关联部门并参与用户维护。它不直接等同于权限角色：岗位表达组织职责，角色表达系统授权。

## 个人中心

个人中心允许登录用户查看和修改自己的资料、头像或密码。修改密码时应验证旧密码，并让高风险会话按安全策略重新认证。

## 推荐验证

- 用户创建后能通过对应登录方式认证。
- 停用用户无法继续建立新会话。
- 部门移动后数据权限范围随组织树正确变化。
- 导入失败行能返回明确原因，不产生半完成关系数据。
