## 操作日志

带有 `@Log` 的业务方法会记录操作标题、业务类型、操作人、请求信息和执行状态。操作日志支持查询、导出、按 ID 删除和清空。

不要把密码、Token、验证码、私钥或完整敏感请求体写入日志。对包含个人信息的字段应配合脱敏输出。

## 登录日志

登录日志记录成功和失败认证，可用于异常登录排查和账号锁定分析。管理端支持查询、导出、清理以及按用户名解锁。

## 在线用户

在线用户来源于 Sa-Token 会话。管理员可以查看会话并强制退出指定 Token；当前用户也可退出自己的其他会话。

## 缓存监控

`GET /monitor/cache` 返回缓存监控信息，需要 `monitor:cache:list` 权限。生产环境只应向受信管理员开放监控数据。
