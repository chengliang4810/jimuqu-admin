---
title: 角色与菜单
description: RBAC、菜单路由、按钮权限与数据范围
---

角色连接用户、菜单权限和数据范围。菜单同时描述前端动态路由、目录、页面和按钮权限标识。

## 菜单类型

- **目录**：组织导航层级。
- **菜单**：对应可访问页面和路由组件。
- **按钮**：对应 `system:user:add` 一类操作权限标识。

`GET /system/menu/getRouters` 根据当前用户生成前端动态路由；`GET /auth/codes` 返回按钮权限码。后端仍必须在控制器上使用 `@SaCheckPermission`，不能把前端隐藏当成安全控制。

## 角色授权

角色模块支持菜单授权、数据范围、状态切换、批量分配或取消用户。数据范围包括全部、自定义部门、本部门、本部门及以下和仅本人。

## 变更顺序

1. 创建菜单并确认权限标识。
2. 将菜单和按钮权限分配给角色。
3. 将角色分配给用户。
4. 重新获取路由与权限码，必要时重新登录刷新会话缓存。

:::caution
删除菜单需要考虑子菜单、角色关联和前端路由。控制器提供级联删除入口，但生产操作前仍应确认影响范围。
:::
