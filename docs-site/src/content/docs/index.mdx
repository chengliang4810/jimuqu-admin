## 面向生产，而不止能跑起来

<div class="home-production-list">

  <p><strong>接口保护</strong><span>RSA 加解密、XSS 校验、限流、幂等与敏感字段脱敏按请求链路生效。</span></p>

## 技术基线

**Java 21** · **Solon 4.0.5** · **Xbatis 1.10.7** · **Sa-Token 1.45.0** · **AutoTable 2.6.1**

项目采用 Maven 多模块结构，默认服务端口为 `5320`，支持 MySQL 与 SQLite，并提供配套的 Vue 管理端。
