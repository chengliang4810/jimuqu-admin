# x-file-storage Solon 与安全排查

## Solon 集成

- 优先按当前项目的 Solon 配置方式接入。
- 依赖 `x-file-storage-solon` 时，先确认是否已有自动装配或插件声明。
- Web 上传流通常由框架管理，不要随意关闭外部流。

## 常见问题

1. 上传后 `FileInfo` 不符合预期：先看原始文件名、路径、平台是否设置。
2. 平台找不到：先查配置项和默认平台。
3. 图片处理失败：先确认图片格式与缩略图后缀。
4. 文件名乱码：先查文件名编码和原始名设置。

## 安全建议

- 限制文件大小、后缀、类型和目录。
- 不接受用户自定义存储路径。
- 不把上传 URL 当成可信输入。
- 对图片和回调中的文本参数做最小必要处理。
