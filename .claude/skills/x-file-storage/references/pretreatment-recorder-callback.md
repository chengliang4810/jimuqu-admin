# x-file-storage 预处理、记录器与回调

## 预处理对象

`fileStorageService.of(...)` 返回预处理链，用于补充：
- 原始文件名
- 路径
- 平台
- 对象关联信息
- 自定义属性

## 记录器

如果项目接入文件记录器：
- 上传成功后可同步记录
- 删除时要确认记录是否同步清理
- 不要把记录器当成存储本身

## 回调与扩展点

常见扩展点通常围绕：
- 上传前处理
- 上传后处理
- 删除后处理
- 文件属性补充

## 注意事项

- 用户可控字段不要直接拼进路径。
- 回调里不要做重业务或阻塞操作。
- 预处理链和记录链不要互相耦合成重复封装。
