## 兼容处理

1. **MinIO**：x-file-storage 最新版 2.3.0 调用 `io.minio.http.Method`，MinIO 9.0.0～9.0.3
   均已删除该类并改为 `io.minio.Http.Method`。使用真实存储适配层签名调用复现了
   `NoClassDefFoundError`，因此采用最新 8.x 版本 8.6.0。补充 OkHttp 5 的 `okhttp-jvm`
   实现依赖，验证 MinIO 适配层签名及 AWS S3 签名。
2. **Sa-Token**：1.46 禁止新登录 ID 包含冒号，新会话改为 `userType_userId`；权限读取、
   在线设备列表、会话清理兼容旧 `userType:userId`。通过 SPI 只注册 `LoginUser`、`RoleDTO`、
   `PostDTO`，保留新版 JSON 类型白名单。关闭 Map 具体实现类元信息，保留嵌套角色 ID 的
   `Long` 类型并支持不可变 Map。多节点部署时应同时升级，避免旧节点解析新登录 ID。
3. **Redisson 4**：Redis 监控改用 `RedisNodes` API，支持单机、集群、哨兵和主从配置；
   调度 Lua 调用改用新版 `LONG`、`LIST` 返回类型。
4. **Excel/JAXB**：采用 Ehcache Jakarta 变体并显式使用 JAXB 4；SMS4J 仅使用旧 JAXB API
   的 `DatatypeConverter`，保留该 API，排除未使用的旧 JAXB 实现，避免两套实现冲突。
5. **JSON 工具**：解包 Hutool `TypeReference` 后交给 Fory，修复文件元数据下载和删除时的
   `Unknown type`，并增加泛型嵌套回归测试。
6. **HTTP 空请求体**：FeatHTTP 在读取未声明长度或显式 `Content-Length: 0` 的流时可能等待客户端关闭
   连接。该问题在 AIO 2.1.3、2.2.0 都能复现。在表单参数解析前，对没有
   `Transfer-Encoding` 的空 HTTP/1 请求使用容器自带的空流并缓存空内容，避免表单解析、
   日志和错误处理阻塞；正常表单和 chunked JSON 均有真实 HTTP 回归测试。
   JUnit 升级后，调度集成测试改用共享计数器的执行增量断言，
   避免依赖测试执行顺序。
7. **文档站**：Astro Check 0.9.11 的 peer dependency 只支持 TypeScript 5/6，因此采用
   最新的 6.0.3，而非 7.0.2。更新 lockfile，并覆盖 `postcss-selector-parser` 到 7.1.7，
   解决间接依赖的 CPU 耗尽漏洞；`npm audit` 为 0。

## Redisson 的 Fory JSON 支持

Redisson **4.8.0 的正式 JAR 已包含**：

- `org.redisson.codec.JsonForyCodec`：JSON 包含 `@class` 类型信息。
- `org.redisson.codec.TypedJsonForyCodec`：显式指定类型，JSON 不包含 `@class`。
- `org.redisson.codec.ForyCodec`：Fory 二进制格式。

不需要额外查找 `redisson-fory-json` 包，使用 `org.redisson:redisson:4.8.0`，加上项目已有的
`org.apache.fory:fory-json:1.7.7` 即可。Redisson 的 POM 将 Fory 声明为 optional/provided，
因此应用必须提供 Fory 运行时。两种 JSON codec 已做真实 ByteBuf 编解码测试，验证中文、
Long、BigDecimal 和类型恢复。本次只验证能力，Redis 现有数据不切换编码格式。
